This mod adds a custom biome Rusty Badlands, which is a variant of the vanilla Badlands biome.

### Features:
- **Custom blocks:** Rust Fragments, Rusty Core, Rusty Sand and Rusty Stone.
- **Rust Fragments:** Leaf-litter type block which generates frequently on the biome surface. Walking/jumping on them has a small chance of giving the **Tetanus Effect**. Repeatedly doing so increases the duration of the effect.
- **Tetanus Effect:** While an entity has this effect, its movement speed and jump strength are decreased, and eating time is increased. Tetanus's strength keeps increasing as long as the effect is active, upto Tetanus X. The debuffs scale with it.
- **Rusty Core:** This block produces rusty geysers randomly, while it has a water block on top of it. The geyser eruptions push entities upwards. It generates frequently on the surface in **Rusty Geyser** structures.
- **Rusty Ball:** A throwable projectile entity, crafted with 4 Rust Fragments and one Slime Ball. It does half a heart of damage and increases the duration of Tetanus Effect by 5 seconds.
- **Configured Features**: Rusty Stone boulders and sparse dried trees.


This mod uses the Terrablender API.
